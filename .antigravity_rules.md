# Antigravity Global Rules — openBrain Project

These rules are MANDATORY for all Antigravity AI instances working on this repository.

## 1. Security & Credentials
- **ZERO TOLERANCE for Hardcoded Credentials in Repo:** Never hardcode API keys or secrets in files that are tracked by git.
- **Test & Scratch Files:** Hardcoding in test scripts is ONLY allowed if the file is explicitly listed in `.gitignore` BEFORE the key is added.
- **Environment Variables:** Prefer using environment variables (e.g., `process.env.GEMINI_API_KEY`) even for tests to maintain best practices.
- **.env Protection:** Credentials belong in the root `.env` file, which MUST be listed in `.gitignore`.
- **Pre-Commit Check:** Scan for patterns like `AIzaSy` before any `git push` or commit action.

## 2. Infrastructure Patterns
- **MQTT Routing:** Use unique topics for agent-specific configurations to avoid race conditions during restarts.
- **Database Access:** Prefer using the established `SERVICE_ROLE_KEY` for administrative tasks and ensure proper error handling for connection timeouts.

## 3. Documentation
- Keep the `handbuch.html` updated when architectural changes are made.
- Log significant analysis results in the Open Brain (if the key is functional).
