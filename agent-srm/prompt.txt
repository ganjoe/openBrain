**CRITICAL: EXACT STRATEGY MECHANICS**
You must deeply understand exactly how the backtest strategy operates:
1. **Trend Strength Indicator:** Calculated daily as `abs(EMA_fast - EMA_slow) / EMA_fast * 100`.
2. **Trend SMA:** A Simple Moving Average (default 50 periods) of the Trend Strength.
3. **Trend Filter (Buy Condition):** The Trend Strength must be strictly GREATER than its SMA. HOWEVER, if a static `trend_threshold` is > 0, this acts as an OR condition: the filter passes if the Trend Strength is greater than its SMA **OR** if it is greater than the `trend_threshold`. Do NOT say it makes the strategy more selective; it actually makes it MORE permissive because there are two ways to pass.
4. **Setup Entry Condition (N-Days):** For `N` consecutive days (controlled by `setup_count_enter_n`, default 4), the daily `low` must be strictly greater than the `low` from `N` days ago (`low[i] > low[i-N]`).
5. **Green Candle Confirmation:** The setup day must close as a green candle (`close > open`).
6. **Entry Execution:** If the Trend Filter, Setup Condition, and Green Candle rules are ALL true, a position is opened on that exact day at the `close` price.
7. **Position Sizing:** The system calculates the risk-based size `(Capital * risk_pct) / Risk_Range` (where `Risk_Range = max(high - low, min_tick)`). This size is capped by the maximum allowed position sizing parameter `position_size_pct` (default 10): `cap_size = int((Capital * position_size_pct / 100) / close)`. The final position size is `min(risk_size, cap_size)`.
8. **Exit Rule (Sell):** There are two parallel exit conditions:
   - **Setup Count Exit (End of Day):** If the Setup Exit Condition (controlled by `setup_count_exit_n`, default 4) evaluates to FALSE on day T-1, the position is closed on day T at the `close` price. The Trend Strength is completely ignored for exits.
   - **Volatility Stop / VStop (Intraday):** A trailing ATR-based stop. `ATR` is calculated over `vstop_period` (default 14). The stop is set at entry as `close - (vstop_multiplier * ATR)` (default mult 2.0). Every subsequent day, the trailing stop is moved up: `Stop = max(Stop, close - vstop_multiplier * ATR)`. If the daily `low` drops below this stop line, the position is immediately closed (intraday) at the stop price.
   - **Priority:** The intraday VStop triggers before the end-of-day Setup Count exit.
